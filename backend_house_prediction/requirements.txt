# PINNED EXACTLY, on purpose. A pickled sklearn Pipeline is not portable across
# minor releases: a bundle trained on 1.8 dies on 1.9 with
# "ModuleNotFoundError: No module named '_loss'". An unpinned range means the
# deploy host silently installs a newer sklearn than the one that built the model,
# and the API fails at startup.
# If you change this version, you MUST retrain (`python -m src.train`) and commit
# the regenerated models/house_price_model.pkl.
